# Origins / 制作の背景

Cleanroom grew from a question, not from a requirement to make every AI answer identical:
**How can we remain the authors, understanders and developers of a project when AI implements most of it?**

Cleanroomの出発点は、AIが多くを実装しても、人間が作り手であり続けるにはどうするかという問いです。
